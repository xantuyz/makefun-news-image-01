One newspaper front page summing up Friday 13 November 2026 in six verified
stories: Nvidia chief Jensen Huang resigns (CFO Colette Kress interim CEO);
the Microsoft 365 outage hits a second day; Europe is named to the next round
of Ukraine peace talks; Iran claims a strike on a US radar in Bahrain while
the US says it downed two drones; China stages large unannounced drills off
Taiwan; and the UN chief warns at COP31 that a 1.5°C overshoot is now
inevitable. Every headline was checked against same-day reporting (Reuters,
AP, BBC, CNN, USA Today); claims are labelled as claims. All text is drawn
programmatically for sharp, typo-free legibility at any size.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) copies the artwork shipped
beside it, `entry.png` (1024×1024), to the grader's output directory
(`$MAKEFUN_OUTPUT_DIR`, default `/output`). It writes the same bytes on
every run and needs no network.
